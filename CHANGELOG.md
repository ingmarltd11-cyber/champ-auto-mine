# Changelog

## 1.1.0 - 2026-11-17

### Added

- Optional Mod Menu 17.0.1 integration.
- In-game keybind editor with rebind and reset.
- Human Mode with light view sway and short randomized pauses.
- Wordmark logo for the README and release.

### Changed

- Config screens return to Mod Menu when opened from the mod list.
- Default keybinds remain F6 and F7.

## 1.0.0 - 2026-11-17

### Added

- Standalone Fabric mod for Minecraft 1.21.11.
- Native Minecraft GUI with `F6` open and `F7` toggle keybinds.
- Yaw and pitch locking.
- Forward and attack automation.
- Lava and fire scanning with automatic side strafe.
- Persistent settings in `config/champ-auto-mine.json`.
- Mod icon, screenshot, README, MIT license and security notes.
- Release jar and sources jar.
